# Intel-Legacy-Buffer-Fix-Arch-Linux-
Un script automatizado diseñado para corregir los fallos de renderizado (patrones de líneas verticales o corrupción de pantalla) en GPUs Intel integradas de legado (Gen 2 a Gen 7 como Sandy Bridge, Ivy Bridge, etc.) bajo el servidor gráfico X11 y entornos ligeros (`bspwm`, `i3wm`).
